NH Connect

Connection is community infrastructure.

Help build a more connected queer New Hampshire.

NH Connect is an invitation-only digital directory and collaboration network for New Hampshire’s LGBTQIA+ and BIPOC-affirming organizations, businesses, advocates, and community leaders. It brings updates, events, resources, projects, and coalition work into one accessible, privacy-conscious platform.
